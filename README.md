# Code Reader

ChatGPTが作成したコードを貼り付け, 読解に必要な構文・関数・コマンドを抽出する個人向け学習アプリです．

`index.html` をブラウザで開いて「サンプルコード」→「構文を抽出する」を試してください．Pythonの基本構文, NumPy, Matplotlib, pathlibの代表的な記法とBash/JavaScriptの一部を辞書方式で検出します．該当する行, 基本的な意味, 簡単な使用例, 注意点, 理解済みチェックを表示します．入力・学習履歴はブラウザのlocalStorageに保存されます．

この版はオフラインで動く辞書式解析です．真のAI読解ではなく, コード全体の実行結果や各関数の実際の意味を保証しません．誤検出, 未検出もありえます．ChatGPT APIの料金は発生しません．

iPhoneから使うにはこの `index.html` をGitHub PagesなどでHTTPS公開し, Safariからホーム画面に追加してください．保存したデータはデバイス間で自動同期されません．バックアップを定期的に作成してください．

## Ver. 0.3 — 別タブで構文レッスン

学習すべき構文を選択すると `lesson.html` が新しいタブで開き, 基本解説, 短い例, 読み方, 貼り付けたコードの該当箇所, 理解済みチェックを表示します．GitHub Pagesには `index.html` と `lesson.html` を同じ階層にアップロードしてください．データは従来の `code-reader-v2` ローカルストレージを引き継ぎます．
