# Code Reader v0.4

UIを刷新したコード読解学習アプリです．既存の構文抽出・別タブ解説・ノート履歴・学習済みチェック・JSONバックアップを維持しています．

## 更新
GitHubの code-reader リポジトリで Add file → Upload files から `index.html` と `lesson.html` を同名で上書きしてください．Commit changes で反映します．更新前のデータは念のためJSONでバックアップしてください．

## デザイン
控えめなセージグリーン, 温かみのあるオフホワイト, エディトリアルな余白, 実際の押下で沈み込む立体ボタンを採用しています．外部ライブラリや画像には依存しません．

## 注意
現在の構文解析は辞書式であり, AI解説ではありません．コードは実行されません．入力と学習履歴はブラウザ内のlocalStorageに保存します．
