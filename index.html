Code Readerコードを覚えるのではなく, 読めるようにする．

コードを貼って, 必要な文法から学ぶ．

長いプログラムから構文・関数・コマンドを抜き出し, 実際の行と結びつけて解説します．コードは実行しません．

01 / コードを入力

オフラインの辞書式解析です．検出した構文の基本的な意味を説明しますが, コード全体の意図や複雑な動作をAIが理解する機能ではありません．

02 / 学習すべき構文 クリックで別タブへ ↗

コードを入力してください
抽出後, 重要な構文がここに表示されます．

構文をクリックすると, 新しいタブで解説と簡単な使用例を表示します．

03 / 学習履歴

解析結果と理解済みの項目を, このブラウザに保存します．

重要：データは端末・ブラウザごとに保存されます．データ消去に備えてバックアップしてください．秘密情報は貼り付けないでください．
